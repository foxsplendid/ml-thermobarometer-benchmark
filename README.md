# ML Thermobarometer Benchmark Protocol

---

# Part I: Project Overview

## 1. Objective
This project builds and evaluates machine-learning thermobarometer models under a reproducible, modular, and publication-ready workflow. The core objectives are:

- Compare data, model, and correction strategies under a unified protocol.
- Perform independent modeling and evaluation for temperature (T) and pressure (P).
- Provide an integrated toolchain for the main benchmark, stability analysis, learning-curve analysis, error propagation, and offline figure generation.

## 2. Core Features

- Modular experiment framework: `M1 (Data) x M2 (Model) x M3 (Correction) x Feature Set`.
- Strict leakage control: scaling, augmentation, and correction are fitted only within training folds.
- Dual feature-set comparison: `NoLiquid (9 features)` vs `Liquid (18 features)`.
- Independent T/P pipelines: separate training and seed derivation for each target.
- Decoupled tooling: the main benchmark and auxiliary analyses run independently.

## 3. Current Experimental Design

### 3.1 Module System

- `M1 DataModule`: `raw` / `balanced` / `augmented`
- `M2 ModelModule`: `ert` / `catboost` / `stacking`
- `M3 CorrectionModule`: `none` / `residual` / `segmented`
- `M4 UncertaintyModule`: `MCUncertaintyEstimator`

### 3.2 Main Experiment Matrix
The main benchmark includes 24 experiments = 12 base configurations x 2 feature sets:

- `E01-E03`: `raw` + (`ert`/`catboost`/`stacking`) + `none`
- `E04-E06`: `balanced` + (`ert`/`catboost`/`stacking`) + `none`
- `E07-E09`: `augmented` + (`ert`/`catboost`/`stacking`) + `none`
- `E10-E12`: `augmented` + (`ert`/`catboost`/`stacking`) + `segmented`

### 3.3 Feature Sets

- `NoLiquid` (9 features)
```python
['SiO2.cpx', 'TiO2.cpx', 'Al2O3.cpx', 'Cr2O3.cpx',
 'FeO.cpx', 'MgO.cpx', 'MnO.cpx', 'CaO.cpx', 'Na2O.cpx']
```

- `Liquid` (18 features)
```python
['SiO2.cpx', 'TiO2.cpx', 'Al2O3.cpx', 'Cr2O3.cpx',
 'FeO.cpx', 'MgO.cpx', 'MnO.cpx', 'CaO.cpx', 'Na2O.cpx',
 'SiO2.liq', 'TiO2.liq', 'Al2O3.liq', 'FeO.liq',
 'MgO.liq', 'MnO.liq', 'CaO.liq', 'Na2O.liq', 'K2O.liq']
```

### 3.4 Data Splitting and Stratification Strategy

- Fixed test set: generated by `prepare_splits()` using P-T grid sampling.
- Main benchmark: `10-fold Stratified CV` on P-T bins.

## 5. Configuration

`config.py` is the single configuration entry point (`get_config_dict()`). Key configuration groups include:

- Data and features: `data_path` / `data_encoding` / `feature_sets` / `target_T` / `target_P`
- Cross-validation: `n_splits` / `random_seed`
- Model defaults: `model_defaults.ert` / `catboost` / `stacking` / `rf`
- Augmentation and uncertainty: `augmentation.n_aug` / `uncertainty.n_mc` / `uncertainty.percentiles`

# Part II: Run Guide

## 1. Environment Setup

```bash
pip install -r requirements.txt
```

## 2. Quick Start

### 2.1 Installation Check
```python
from src import (
    RawDataModule, BalancedDataModule, AugmentedDataModule,
    ExtraTreesModel, CatBoostModel, StrictOOFStacking,
    NoCorrection, SegmentedLinearCorrector,
    Pipeline, StratifiedCVProtocol
)
print('OK')
```

### 2.2 Quick Test
```bash
python main.py --test
```

### 2.3 Main Benchmark (24 experiments)
```bash
python main.py
```

## 3. Sub-Experiment Scripts

### 3.1 Stability Analysis
```bash
python tools/run_stability.py --exp-id E07_stability_nj4 --model-module ert --data-module augmented --corr-module none --feature-set Liquid --n-repeats 1000
```

Merge segmented runs:
```bash
python tools/run_stability.py --merge-dir results --exp-id E07_stability_nj4 --output-dir results
```

### 3.2 Learning-Curve Analysis
```bash
python tools/run_learning_curve.py --feature-set liq --models ert stacking --repeats 30 --n-splits 10
```

Merge segmented runs:
```bash
python tools/run_learning_curve.py --merge-dir results/learning_curve --output-dir results/learning_curve
```

### 3.3 Analysis Error Propagation
```bash
python tools/run_error_propagation.py --exp-id E07_ert_augmented_none_liq --model-module ert --data-module augmented --corr-module none --feature-set Liquid --n-mc 1000
```

### 3.4 Offline Plotting (SHAP enabled by default)
```bash
python tools/plot_offline_figures.py --selected-only
```

Notes:
- This script only reads existing artifacts under `results/` and does not retrain models.
- SHAP runs by default in the offline plotting flow with internal defaults: `max_samples=300`, `bg_k=50`, `force=True`.

## 4. Key Outputs

- `results/metrics_summary.csv`: main benchmark summary.
- `results/effect_table.csv`: effect table relative to baseline.
- `results/models/*.joblib`: serialized model artifacts.
- `results/stability/`: stability-repeat outputs.
- `results/learning_curve/`: learning-curve outputs.
- `results/error_propagation/`: error-propagation outputs.
- `results/figures/`: offline plotting outputs.
